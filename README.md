## Projects

| Project | What it is | Tools |
|---|---|---|
| [harbor-supply-migration](https://github.com/SheltonRazik/harbor-supply-migration) | A mock ERP data migration: cleaning, duplicate matching, loading to an SAP-style model, and reconciling open receivables to the cent | SQL, Python, rapidfuzz |

| [expat-retirement-simulator](https://github.com/SheltonRazik/expat-retirement-simulator) | Monte Carlo retirement model for people who work abroad, with currency risk and contract gaps. Includes a Streamlit app | Python, NumPy, Streamlit |
